# Approved popup artwork

`atlas.png` is an unchanged copy of the user-approved image
`codex-clipboard-971ef331-0a3e-460b-86a2-82832c1f9324.png` (896 × 1200).

The source coordinates live in `../../popup-art.js`; component placement is in
`../../popup-reference.css`. Inline SVG view boxes sample the original pixels.
Paper uses nine slices and a repeating interior texture. Heart, broom and hamper
silhouettes use SVG clipping; caption backgrounds use an alpha filter. The
reference is not used as a full-screen screenshot behind the controls.

Fixed Chinese labels and fixed 800/700 prices use the approved artwork. Coins,
level, life count and recovery time remain connected to the saved player state.
The default zero-life meter is sampled directly; other counts use live text.
Other languages use live labels on the same blank button skins.

The life panel intentionally has a close button and two refill actions, following
the user's subsequent instruction to remove Continue. Failure has only Restart,
matching the approved reference. Continue in other dialogs remains green.
