# Victory UI

`reference.webp` is the archived victory-layout reference. The bear, leaves and
books were removed at the user's request; the reference is no longer loaded at
runtime. The result panel uses the project's approved cream paper, coral close button
and sage green primary button from `popup-art.js` / `popup-reference.css`.

The large preview uses the current level's clean background, preserving that
room's camera and furniture geometry. It is uniformly scaled and cropped by the
preview frame. The reference balcony scene is not substituted for the level.

Elapsed time comes from the session clock, which stops on completion and survives
saved-session restoration. The existing two-second finish animation and reward
settlement are preserved. Close returns to Home; Next starts the next display
level once. Editor preview retains Play again for its current draft.

No life meter, new-record label or rating stars are included. Portrait layouts use
a large picture; short landscape layouts place the picture beside the result.
